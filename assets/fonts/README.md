# Bundled fonts

All fonts are licensed under the SIL Open Font License 1.1 (see the OFL-*.txt files).

- Cinzel (variable, weight axis) — animal-name titles in Phonk / Chase / Documentary edits
- Cormorant Garamond (variable, weight axis) — Cinematic titles
- Anton, Bebas Neue — Showdown card headers, stat pills, stamps

Source: https://github.com/google/fonts (ofl/). Presets reference fonts by a logical name such as
`Cinzel-Bold.ttf`; `wildcut/render/text.py` resolves that to the variable file plus a named instance.
